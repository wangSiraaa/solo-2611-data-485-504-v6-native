# 候选材料角色

`rights.py` 是不依赖业务行的生产容量权利 SDK；`warehouse_rows.py` 是真实 SQLite 所属行的生产入仓/删除服务。`examples.json` 是合成配置与输入，不是参考答案。

普通消费归还、单次转移、单行入仓和删除可运行。起点仍存在重复接收/归还造额，以及行批次失败后容量消费已经提交的问题。需要修复公开合同；允许同站共享数据库事务、成熟设施或共享实现，不以文件数量判断模块。

作者探针及测试用 LocalQuotaFixture 位于候选材料外，仅用于隔离行事务问题。它没有跨站转移实现，不是第三生产职责，也不是完整答案。最终行为以题目正文为准。
